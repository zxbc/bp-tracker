# bp-tracker

A simple, fast Android app for recording blood pressure (systolic / diastolic) and heart rate.

Open the app → type digits on a numpad → the reading is auto-parsed into `SYS / DIA · HR` → confirm → saved with a timestamp → a 7-day chart (and a spreadsheet-style list) shows your history.

Status: **v0.1.3** — released, tested on device (chart card wraps content, legible axis labels, dark-theme text audit, versioned APK). Download: [bp-tracker-v0.1.3-debug.apk](https://github.com/zxbc/bp-tracker/releases/download/v0.1.3/bp-tracker-v0.1.3-debug.apk) (minSdk 26). Design and release notes: [docs/PLAN.md](docs/PLAN.md).
